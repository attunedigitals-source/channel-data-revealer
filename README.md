# Storyframe — YouTube Production Studio

Storyframe is an end-to-end workspace for building research-driven, faceless YouTube documentaries. It brings the production line into one place: competitor research, idea development, title and thumbnail packaging, claim verification, story mapping, AI-assisted script drafting, original thumbnail image generation, Google Flow scene planning, production checks, publishing preparation, and post-upload analytics. AI drafts use the connected Gemini key and flag unsupported claims for source review.

The production workspace supports multiple video projects and saves working data in the current browser. Use **Export** to download a JSON backup of the active project. Google Flow is an external production tool; Storyframe prepares and organizes scene prompts but does not generate Flow footage directly.

The $10,000/month revenue figure is a user-set business target. It is not a forecast or a guarantee.

The existing channel research, competitor analysis, thumbnail analysis, title generation, audience psychology, and story-map tools remain available below the production workspace.
